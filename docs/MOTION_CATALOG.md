# Motion, camera and effects catalog

> Generated by `scripts/generate_motion_docs.py` from `remotion-composer/src/lib/motion-catalog.json`. Do not edit by hand.

Camera moves are 2D approximations on stills/video (scale, translate, rotate, blur, parallax). True 3D moves (real orbit, pass-through, fly-through) need AI video generation; use each move's ai_prompt for that.

Vocabulary draws on: aicameramovements.com, melies.co/cinematic-techniques, eyecannndy.com, grokfilm.app (vocabulary only). Move names follow common cinematography terms; every move has its own implementation and AI-video prompt written for this project.

**83 camera moves · 34 transitions · 59 effects · 12 text modes**

## How to use it

```json
{
  "autoCamera": true,
  "defaultTransition": "dissolve",
  "fx": [
    {
      "type": "film_grain",
      "intensity": 0.25
    },
    "vignette"
  ],
  "cuts": [
    {
      "id": "c1",
      "source": "img.jpg",
      "type": "stat_card",
      "stat": "1,3 s",
      "subtitle": "LUNA",
      "backgroundImage": "img.jpg",
      "camera": {
        "move": "dolly_in",
        "origin": {
          "x": 61,
          "y": 52
        },
        "intensity": 1.0
      },
      "fx": [
        "halation",
        "grade_teal_orange"
      ],
      "transition_out": "whip_pan_right",
      "in_seconds": 0,
      "out_seconds": 5
    }
  ],
  "overlays": [
    {
      "type": "focus_ring",
      "in_seconds": 1,
      "out_seconds": 4,
      "x": 66,
      "y": 48,
      "radius": 150,
      "text": "La Luna"
    }
  ]
}
```

- `camera`: a move id/alias, or a custom spec `{move, intensity, origin:{x,y}, from, to, ease, parallax, shake, delay, hold, reverse, freezeAt}` (state: `s` scale, `x`/`y` percent, `r` degrees, `b` blur px).
- `origin` is the point (percent of the frame) the camera zooms toward — use it to *point at* an object.
- `fx`: strings or `{type, ...params}`; the top-level `fx` applies to every scene.
- Transitions: `transition_out` of a cut (or `transition_in` of the next), duration `transition_duration` seconds (default 0.4).

## AI-video prompts (for providers that generate real camera motion)

- **static** — static. Movement: Locked-off frame, no movement.. Speed: still. Framing: same angle, height and lens for the whole clip. End: settle on a stable final composition.
